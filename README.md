# 像素绝地求生 · Pixel Battlegrounds

单文件 HTML5 Canvas 像素风“大逃杀”小游戏，**零依赖、零构建**，浏览器直接打开 `index.html` 即可游玩。

## 运行

直接双击 `index.html`，或用任意静态服务器：

```
npx serve .
# 然后浏览器打开 http://localhost:3000
```

推荐使用 Chrome / Edge 桌面浏览器（需要键盘鼠标）。

## 界面布局

- **中央地图区**：像素方块世界，含草地、湖泊、公路、9 个城镇、房屋、树木、岩石、物资箱
- **左上角小地图**：实时位置、当前/下一个安全区、附近敌人、枪声标记
- **顶部状态栏**：生命值、护甲值、剩余人数、击杀数、安全区阶段与缩圈倒计时
- **右上角操作区**：飞机阶段显示脉动的“跳伞”按钮
- **底部武器/道具栏**：4 个武器槽 + 绷带 / 医疗箱 / 能量饮料
- **L 背包 / U 大地图**：覆盖层，显示物资详情与全场安全区

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 冲刺 |
| 空格 | 飞机阶段跳伞；地面短距跳跃冲刺 |
| J / 鼠标左键 | 射击 / 近战 |
| 鼠标右键（按住） | 开镜瞄准（散布更小、视野放大） |
| K | 换弹夹 |
| 1-4 / 鼠标滚轮 | 切换武器 |
| F | 附近有武器时替换当前枪 |
| Z / X / C | 绷带 / 医疗箱 / 能量饮料 |
| L | 背包（查看血量、弹药、药品并使用） |
| U | 战术大地图 |
| M | 音效开关 |

## 核心玩法

1. **跳伞入场**：开局乘飞机横向巡航，可随时按空格选择落点；空中可用方向键控制滑翔，落地开战
2. **资源搜集**：房屋门口/室内、城镇广场、野外物资箱周围刷新发光光团（武器/弹药/护甲/药品），靠近自动拾取。武器包含 近战匕首、P92 手枪、UMP 冲锋枪、M416、AKM、Kar98 狙击枪
3. **战斗系统**：射击有射速、弹匣、散布、换弹；连发产生后坐力（准星上扬 + 屏幕震动），被击中时瞄准镜额外上扬；右键开镜降低散布并放大视野；狙击枪高伤害低射速
4. **安全区缩圈**：7 个阶段不断缩小，圈外按阶段加重持续掉血；蓝圈为当前安全区，白圈为下一个安全区
5. **AI 敌人（共 35 名）**：会跳伞、进屋/向物资箱搜刮、自动捡枪换装、换弹、打药、进圈、卡墙脱困；敌人相遇会互相交火；**玩家在其索敌范围内时拥有最高仇恨优先级与更大索敌半径**，会主动追击玩家

活到最后（仅剩自己）即“吃鸡”。
